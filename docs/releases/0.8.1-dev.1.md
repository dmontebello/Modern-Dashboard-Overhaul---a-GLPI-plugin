## Provenienza e SHA512

Il commit funzionale che contiene queste note è lo SHA sorgente da testare, non
il successivo commit bot che pubblica i file. SHA esatto, build ID e data UTC
sono generati in build-info.json durante la CI del checkout pulito. Il checksum
finale è nel sidecar Modern_Dashboard_Overhaul_0.8.1-dev.1.zip.sha512 e nel record
generato docs/releases/0.8.1-dev.1.build.json, consultabili sul branch Dev dopo CI.
Non è possibile incorporare l'hash finale di un archivio all'interno dello stesso
archivio senza autoreferenza: il manifest interno copre invece ogni file,
compreso build-info.json. Una build locale sporca è marcata dirty e non pubblicabile.
